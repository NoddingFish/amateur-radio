# 业余无线电 A 类题库练习

基于 CRAC 2025 年版 A 类题库的静态答题网站，包含全部 683 道题。

## 使用

直接用浏览器打开 `index.html`，无需安装依赖或启动服务。也可将网站文件部署到任意静态网站托管服务。

首页以「A 类题库」为标题，集中显示顺序练习与分类速记的进度，并提供顺序练习、分类速记、错题本、我的收藏和模拟考试入口。顺序练习直接进入答题并恢复上次位置；错题本、收藏直接进入做题，题号与导航按各自集合连续编号；分类速记先展示 13 个主题，点击主题查看其记忆组，再点击记忆组查看速记内容。主题和记忆组均显示准确的题号范围，不连续的题号分段显示。做题页将练习模式合并至品牌旁边，正文直接展示题目；提示、收藏和题目导航均使用无边框图标，题目导航点击后打开弹窗。答题页面为 `practice.html`，原有练习、收藏、错题和考试记录继续使用。

准备考试时，建议先打开 `study.html`：把全部 683 题归为 13 个主题、70 个记忆组，提供核心规则、记忆线索、易错点和每天约 1 小时的 14 天路线。每组可先遮住答案口头自测，再练同组变式；也支持按主题或按复习天练习。

## 功能

- 按源 PDF 顺序连续编号 1–683，保留原始题号、知识点和来源页码。
- 单选点击选项自动提交；多选点击按钮或按回车提交，显示对错、正确选项及误选，误选项背景显示为红色。
- 多选题须与正确答案完全一致，漏选、多选均判错。
- 支持左右方向键切换上一题、下一题，以及题号跳转、答题导航和重新作答；输入题号时不触发切题快捷键。手机答题区左滑下一题、右滑上一题，上下滚动和弹窗内滑动不会切题。
- 切题时两张题卡同时左右滑动：下一题从右侧进入，上一题从左侧进入；按钮、方向键、手机滑动和自动切题使用相同过渡。连续切题会取消上一段动画，系统开启“减少动态效果”时直接切换。
- 未判分的选中项使用蓝色背景，判分后正确项为绿色、误选项为红色。
- 普通练习默认提交后自动下一题，展示结果约 0.9 秒后切题；不再显示开关。
- 首页显示顺序练习的答对、答错与未检查数量，以及分类速记已掌握的记忆组与进度，适配电脑与手机屏幕。
- 返回、跳转、切题、收藏等操作统一使用 SVG 线条图标；鼠标点击不显示焦点框，键盘操作使用柔和绿色的焦点提示。
- 错题本：所有练习中答错的题目自动收录，也会首次导入已有记录中的错题；答对后仍保留，可手动移出并集中练习。
- 我的收藏：点击题目右上角的星标添加或取消收藏，支持单独练习收藏的题目。
- 分类速记、跨分类搜索、考前对照表，以及浏览器内保存的“已掌握”自评标记。
- 练习题右上角的提示图标弹窗展示速记口诀、解题线索和避坑提醒，覆盖全部 683 题；原题存在表述疑点时另附本题提醒。可通过关闭按钮、Esc 或点击遮罩关闭；查看提示会取消本题自动跳转，弹窗内不触发切题快捷键。模拟考试交卷后也可查看提示。
- 模拟考试随机抽取 32 单选＋8 多选，题目与选项顺序均打乱；限时 40 分钟，交卷或到时后统一判分，答对 30 题合格。交卷前可修改答案，刷新保留试卷、选项顺序、作答和截止时间，交卷后支持查看逐题结果及重新组卷。错题（含未答题）自动收录，模拟考试记录与普通练习分开保存。

作答选项、判分结果和当前位置自动保存在当前浏览器，刷新或关闭后重新打开可继续；顺序、记忆组、主题、每日和模拟考试分别保存。手机端提供底部切题栏、题目导航入口和适合触控的按钮。
模拟考试、错题本、我的收藏统一由首页入口进入。错题与收藏跨练习模式共用，错题本、收藏练习各自保存作答进度。
分类速记首次进入仅显示学习概览，点击分类后切换为该类的记忆组；电脑端通过分组按钮一次查看一组，手机端通过弹窗选择分类和记忆组，默认收起分组内容。做题页在电脑和手机端均通过题号前的导航图标打开弹窗，选择题目或跳转后自动关闭。
若浏览器禁止本地存储，页面会提示无法保存，当前页面内仍可作答。
速记页的掌握标记单独保存在当前浏览器；不同浏览器、浏览器内嵌面板及 `file://`/HTTP 地址不一定共享。

## 数据来源与已知问题

题目来源：[CRAC 发布的业余无线电台操作技术能力验证题库（2025 年版）](https://www.crac.org.cn/?p=1287)。题库内容版权归原权利人所有。

A 类按官方分库确定，不能按 LK、LY、LX 题号前缀判断。源 PDF 与官方 A 类文件的 SHA-256 一致，校验值记录在 JSON 元数据中。

- 第 462 题（`MC1-0665` / `LK0944`）在源 PDF 中仅列出图片文件名；现已补入用户提供的 `images/LK0944.jpg`，练习、模拟考试与分类速记的原题区均可显示。核查全部 683 题和原 PDF 的 165 页，仅这一题引用配图，未发现其他缺图。
- `MC1-0014`、`MC1-0016` 的原编号与答案数量不一致；保留原编号，页面按实际答案数量显示为多选题。

速记材料另标出了源题第 366 题 SSTV 编码、第 647 题平均值／有效值等表述疑点；原题及判分数据未更改。复习时区分“原题标准选项”和“可推广的知识规律”。

编辑分类 JSON 后，可运行 `python scripts/build-study.py` 重新生成速记数据与 Markdown，并校验 683 题无遗漏、无重复。

依据 [CRAC 官方考核标准](https://www.crac.org.cn/userfiles/file/20250728/20250728133610_2877.pdf)，A 类为 40 题（32 单选、8 多选），40 分钟，答对 30 题合格；多选须与标准答案完全一致。主题题量不代表正式试卷的抽题比例。
