# 业余无线电 A 类题库练习

基于 CRAC 2025 年版 A 类题库的静态答题网站，包含全部 683 道题。

## 使用

直接用浏览器打开 `index.html`，无需安装依赖或启动服务。也可将网站文件部署到任意静态网站托管服务。

准备考试时，建议先打开 `study.html`：把全部 683 题归为 13 个主题、70 个记忆组，提供核心规则、记忆线索、易错点和每天约 1 小时的 14 天路线。每组可先遮住答案口头自测，再练同组变式；也支持按主题或按复习天练习。

## 功能

- 按源 PDF 顺序连续编号 1–683，保留原始题号、知识点和来源页码。
- 支持单选和多选，提交后显示对错、正确选项及误选。
- 多选题须与正确答案完全一致，漏选、多选均判错。
- 支持上一题、下一题、题号跳转、答题导航和重新作答。
- 显示本次答对、答错及未检查数量，适配电脑与手机屏幕。
- 分类速记、跨分类搜索、考前对照表，以及浏览器内保存的“已掌握”自评标记。
- 混合练习随机抽取 32 单选＋8 多选；仍采用逐题检查，可自行计时检验，刷新重新抽题。

切换题目会保留当前页面内的作答；刷新或关闭页面会重置进度。
速记页的掌握标记单独保存在当前浏览器；不同浏览器、浏览器内嵌面板及 `file://`/HTTP 地址不一定共享。

## 数据来源与已知问题

题目来源：[CRAC 发布的业余无线电台操作技术能力验证题库（2025 年版）](https://www.crac.org.cn/?p=1287)。题库内容版权归原权利人所有。

A 类按官方分库确定，不能按 LK、LY、LX 题号前缀判断。源 PDF 与官方 A 类文件的 SHA-256 一致，校验值记录在 JSON 元数据中。

- `MC1-0665` 在源 PDF 中仅包含 `LK0944.jpg` 文件名，未提供实际配图；答题页面会显示缺图提示。
- `MC1-0014`、`MC1-0016` 的原编号与答案数量不一致；保留原编号，页面按实际答案数量显示为多选题。

速记材料另标出了源题第 366 题 SSTV 编码、第 647 题平均值／有效值等表述疑点；原题及判分数据未更改。复习时区分“原题标准选项”和“可推广的知识规律”。

编辑分类 JSON 后，可运行 `python scripts/build-study.py` 重新生成速记数据与 Markdown，并校验 683 题无遗漏、无重复。

依据 [CRAC 官方考核标准](https://www.crac.org.cn/userfiles/file/20250728/20250728133610_2877.pdf)，A 类为 40 题（32 单选、8 多选），40 分钟，答对 30 题合格；多选须与标准答案完全一致。主题题量不代表正式试卷的抽题比例。
