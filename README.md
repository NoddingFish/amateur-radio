# 业余无线电 A 类题库练习

基于 CRAC 2025 年版 A 类题库的静态答题网站，包含全部 683 道题。

## 使用

直接用浏览器打开 `index.html`，无需安装依赖或启动服务。也可将网站文件部署到任意静态网站托管服务。

## 功能

- 按源 PDF 顺序连续编号 1–683，保留原始题号、知识点和来源页码。
- 支持单选和多选，提交后显示对错、正确选项及误选。
- 多选题须与正确答案完全一致，漏选、多选均判错。
- 支持上一题、下一题、题号跳转、答题导航和重新作答。
- 显示本次答对、答错及未检查数量，适配电脑与手机屏幕。

切换题目会保留当前页面内的作答；刷新或关闭页面会重置进度。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网站入口 |
| `styles.css` | 页面样式 |
| `app.js` | 作答、判分及导航逻辑 |
| `questions.js` | 浏览器直接读取的完整题库数据，顺序与完整 JSON 一致 |
| `A类题库.json` | 结构化完整 A 类题库，共 683 题 |
| `A类题库_LY子集.json` | LY 原题号子集，共 138 题，对应 141 个原题号 |
| `A类题库.pdf` | 原始题库文档 |

## 数据来源与已知问题

题目来源：[CRAC 发布的业余无线电台操作技术能力验证题库（2025 年版）](https://www.crac.org.cn/?p=1287)。题库内容版权归原权利人所有。

A 类按官方分库确定，不能按 LK、LY、LX 题号前缀判断。源 PDF 与官方 A 类文件的 SHA-256 一致，校验值记录在 JSON 元数据中。

- `MC1-0665` 在源 PDF 中仅包含 `LK0944.jpg` 文件名，未提供实际配图；答题页面会显示缺图提示。
- `MC1-0014`、`MC1-0016` 的原编号与答案数量不一致；保留原编号，页面按实际答案数量显示为多选题。
